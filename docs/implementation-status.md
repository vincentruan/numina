## 技术栈

**前端：**
- Vue 3 + TypeScript
- Vant UI 4
- Pinia (状态管理)
- Vue Router
- ECharts (图表)
- html2canvas (分享功能)

**后端：**
- Python + FastAPI
- SQLAlchemy ORM
- APScheduler (定时任务)
- Pytest (单元测试)

**部署：**
- Docker + nginx
- 子路径部署 (/numina/)
