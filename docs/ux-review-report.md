# Numina 家庭资产可视化系统 UX 审查报告

## 执行摘要

本次审查基于对 Numina 系统的端到端测试，包括 API 验证、前端代码分析和移动端用户体验评估。整体而言，Numina 在功能完整性和数据准确性方面表现优秀，但在用户交互路径和移动端体验上仍有优化空间。

**总体评分：7.5/10**

## 测试环境

- **部署方式**：Docker Compose（nginx + FastAPI + Vue 3）
- **访问地址**：http://localhost/numina/
- **测试数据**：
  - 实物资产：房产（200万）、车辆（28万）、iPhone（1万）
  - 金融资产：存款（50万）、基金（10万）
  - 负债：房贷（138万）、车贷（12万）
- **验证结果**：所有 API 接口正常工作，数据计算准确

## 交互路径便捷性评估

### 核心操作流程分析

#### 1. 资产记录流程（当前：4步）
1. 点击底部导航栏"资产" → 进入资产列表
2. 点击"+" FAB 按钮 → 进入资产创建表单
3. 填写表单信息（选择分类、输入名称、价格等）
4. 提交表单

**问题**：步骤过多，对于高频操作不够便捷。

#### 2. 负债记录流程（当前：4步）
与资产记录流程类似，同样存在步骤过多的问题。

#### 3. 仪表盘查看（当前：1步）
- 应用启动后直接进入仪表盘，体验良好

### 导航结构评估

**优点**：
- 底部 Tab Bar 设计符合移动端习惯（总览、资产、负债、家庭、设置）
- 页面层级扁平，最多2层深度

**问题**：
- 资产/负债的"新建"按钮位置不够突出
- 缺少快速操作入口（如语音录入、扫码识别等）

### 改进建议

1. **简化资产录入**：在仪表盘添加"快速添加"卡片，支持一键录入常用资产类型
2. **智能表单**：根据资产类型自动显示/隐藏相关字段，减少用户认知负担
3. **批量操作**：支持一次性录入多个资产（如月度账单导入）

## 数据必要性评估

### 资产创建必填字段

当前必填字段：
- 名称
- 资产类型（实物/金融）
- 分类
- 购入价格
- 当前价值
- 购入日期

**评估**：
- **合理**：核心字段设计合理，覆盖了资产追踪的基本需求
- **可优化**：当前价值可以默认等于购入价格，减少用户输入

### 资产创建可选字段

- 预期寿命（天）
- 年维护成本
- 使用频率
- 位置
- 机构
- 利率
- 到期日期
- 备注

**评估**：
- 字段设计全面，覆盖了各种资产类型的特殊需求
- 但缺乏智能引导，用户可能不知道哪些字段对自己有用

### 负债创建字段

必填字段相对较少，主要包含：
- 名称
- 类型（mortgage/car_loan/credit_card/personal_loan）
- 原始金额
- 剩余金额
- 月供
- 利率
- 起止日期
- 机构

**评估**：字段设计合理，符合负债管理的核心需求。

### 改进建议

1. **字段智能默认**：根据资产类型自动填充合理默认值
2. **渐进式披露**：高级字段默认折叠，用户可按需展开
3. **字段说明**：为专业字段（如日耗成本）提供简明解释

## 视觉美观度评估

### 整体设计

**优点**：
- 采用 Vant 4 组件库，UI 一致性好
- 配色方案合理，使用不同颜色区分资产类别
- 图标设计直观（🏠房产、🚗车辆、📱数码等）
- 响应式设计适配移动端

**问题**：
- 仪表盘信息密度较高，新用户可能感到 overwhelm
- 缺少视觉层次，重要信息不够突出
- 图表样式较为基础，缺乏个性化

### 数据展示

**优点**：
- 货币格式化正确（CNY）
- 百分比显示清晰
- 日耗成本等智能计算字段有价值

**问题**：
- 数字对比不够直观（如净资产变化）
- 缺少趋势箭头或颜色编码来表示增减
- 表格行高偏小，影响可读性

### 图表效果

基于代码分析，系统包含以下图表：
- 净资产趋势图（ECharts）
- 资产配置饼图（ECharts）
- 日耗成本排行
- 投资收益排行

**评估**：
- 图表类型选择合理，覆盖了核心分析需求
- 但缺少交互性（如点击钻取、时间范围选择）
- 移动端图表尺寸可能偏小

### 改进建议

1. **增强视觉层次**：使用字体大小、颜色、间距来区分信息重要性
2. **优化图表交互**：添加触摸交互，支持缩放和详细信息查看
3. **个性化主题**：允许用户选择深色/浅色主题
4. **动画效果**：添加适度的过渡动画提升用户体验

## Top 5 改进建议（按优先级排序）

### 1. 优化资产录入流程（高优先级）
**问题**：当前4步流程对高频操作不够友好
**建议**：
- 在仪表盘添加"快速添加"入口
- 实现智能表单，根据资产类型动态调整字段
- 支持语音输入资产名称和价格

### 2. 改进仪表盘信息架构（高优先级）
**问题**：信息密度过高，新用户学习成本大
**建议**：
- 采用卡片式布局，每个指标独立卡片
- 添加新手引导，逐步介绍各功能
- 提供"简洁模式"选项，隐藏高级指标

### 3. 增强数据可视化（中优先级）
**问题**：图表交互性不足，移动端体验待优化
**建议**：
- 优化 ECharts 配置，适配移动端触摸
- 添加图表间联动（点击饼图某部分，趋势图聚焦该类别）
- 支持自定义时间范围查看历史数据

### 4. 智能字段管理（中优先级）
**问题**：表单字段过多，用户困惑
**建议**：
- 实现渐进式披露，高级字段默认隐藏
- 根据用户行为智能推荐相关字段
- 为专业术语提供 tooltip 解释

### 5. 修复技术细节（高优先级）
**问题**：API 请求需要尾部斜杠，否则返回 307 重定向
**建议**：
- 在 nginx 配置中添加 trailing slash 处理规则
- 或者在后端禁用 FastAPI 的自动重定向
- 确保所有前端请求都包含正确的路径格式

## 结论

Numina 作为家庭资产管理系统，在功能完整性和数据准确性方面表现出色。核心的资产/负债管理、家庭协作、数据可视化功能都已实现并经过验证。

主要改进方向集中在用户体验层面：
1. **简化高频操作**：减少资产录入步骤
2. **优化信息架构**：降低新用户学习成本  
3. **增强交互体验**：提升移动端图表和表单体验

这些改进将显著提升产品的易用性和用户满意度，特别是在目标用户群体（普通家庭用户）中的接受度。
