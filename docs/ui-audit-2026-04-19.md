## P0 — Critical Issues

### 重复资产数据污染列表
- **Page**: `/assets`
- **Component**: 资产列表
- **Issue**: 资产列表中存在大量重复条目（如"招商银行定存"、"工商银行活期"、"美元存款"、"易方达蓝筹"等金融资产各出现 2 次，"Rimowa行李箱"出现 2 次）。87 件资产中实际唯一资产约 44 件，重复率约 50%。这会导致总资产数字虚高，用户无法信任数据。
- **Fix**: 检查 seed 脚本是否被执行了两次；在 `/assets` API 查询中加 `DISTINCT` 或检查 family_id 隔离是否正确；清理重复数据。
- **Effort**: M

### 测试数据泄漏到生产演示账号
- **Page**: `/assets`, `/`
- **Component**: 资产列表、仪表盘
- **Issue**: 列表中出现"测试资产_99143"、"测试资产_99323"、"测试资产"等明显测试数据，与真实演示数据混杂。仪表盘显示"↑ 186.6% vs 上月"的异常涨幅，很可能由测试数据引起。这对演示账号是严重的可信度问题。
- **Fix**: 清理 demouser 账号下的测试资产；seed 脚本应有幂等保护，避免重复插入。
- **Effort**: S

## P1 — Major UX Issues

### 仪表盘资产列表只显示 6 条，无"查看全部"入口
- **Page**: `/` (dashboard)
- **Component**: 资产列表区块
- **Issue**: 仪表盘底部的"资产列表 (6)"只展示 6 条，但实际有 87 件资产。没有"查看全部"按钮或跳转链接，用户无法从仪表盘直接进入完整列表。
- **Fix**: 在"资产列表"标题旁添加"查看全部 >"链接，跳转到 `/assets`。
- **Effort**: S

### 资产详情页信息密度不足，缺少关键字段
- **Page**: `/assets/{id}`
- **Component**: 资产详情
- **Issue**: 详情页只显示名称、类型、分类、购入价格、购入日期、状态、日耗，缺少：使用频率、存放位置、年维护费、标签、备注、预期寿命。"日均成本趋势"区块有标题但无图表内容（空白）。
- **Fix**: 补全所有已填写字段的展示；日均成本趋势图表需要实现或在无数据时显示空状态提示。
- **Effort**: M

### 负债列表缺少还款进度可视化
- **Page**: `/liabilities`
- **Component**: 负债卡片
- **Issue**: 负债列表每张卡片只显示月供金额和剩余金额，没有还款进度条。用户无法一眼看出每笔负债还了多少、还剩多少比例。房贷 ¥1500 万剩余，但没有进度反馈。
- **Fix**: 在每张负债卡片上添加进度条（已还/总额），颜色用绿色渐变表示进度。
- **Effort**: M

### 心愿单缺少储蓄进度和目标达成反馈
- **Page**: `/wishes`
- **Component**: 心愿列表卡片
- **Issue**: 每个心愿只显示优先级、价格、分类、描述，没有"已存/目标"进度条，没有预计达成日期，没有与当前净资产的关联提示。用户无法感知距离目标有多远。
- **Fix**: 添加储蓄进度字段（可选填）；显示"按当前净资产，可负担"或"还差 ¥X"的提示。
- **Effort**: M

### 分类管理页图标显示为原始 icon key 字符串
- **Page**: `/settings/categories`
- **Component**: 分类列表
- **Issue**: 所有分类显示的是原始 icon key（如"icon-home 房产"、"icon-car 车辆"），而不是实际图标。这说明 icon 渲染组件未正确映射 icon key 到 SVG/emoji。
- **Fix**: 检查分类列表组件中 icon 渲染逻辑，确保 `icon-home` 等 key 能正确映射到对应图标；或改用 emoji（与仪表盘分类显示保持一致）。
- **Effort**: S

### 设置页账户信息不完整
- **Page**: `/settings`
- **Component**: 账户信息区块
- **Issue**: "当前用户"下只显示"用户名"和"角色"两个标签，但没有实际值（用户名字段为空，角色显示"成员"但 demouser 实际是管理员）。角色显示与家庭页（显示"管理员"）不一致。
- **Fix**: 绑定实际用户数据到设置页账户信息；统一角色显示逻辑。
- **Effort**: S

## P2 — Minor Polish

### 仪表盘"提醒"区块文案歧义
- **Page**: `/`
- **Component**: 提醒区块
- **Issue**: 显示"即将到期 2 项资产 (2 已过期)"——"即将到期"和"已过期"同时出现在同一行，语义混乱。用户不清楚是 2 项即将到期还是 2 项已过期。
- **Fix**: 分开展示：「即将到期：0 项」「已过期：2 项」，或用不同颜色区分（橙色=即将，红色=已过期）。
- **Effort**: S

### 资产列表无分页或虚拟滚动，87 条全量渲染
- **Page**: `/assets`
- **Component**: 资产列表
- **Issue**: 87 条资产（含重复）全部渲染到 DOM，在低端手机上会有明显卡顿。a11y 树有 880+ 个节点。
- **Fix**: 实现虚拟滚动（Vant List 组件的 `v-infinite-scroll`）或分页加载（每次 20 条）。
- **Effort**: M

### 资产列表排序只有"按价值"，缺少多维度排序
- **Page**: `/assets`
- **Component**: 排序按钮
- **Issue**: 只有一个"按价值"排序按钮，没有按日均成本、按购入日期、按分类排序的选项。
- **Fix**: 改为下拉菜单，提供：按价值、按日均成本、按购入日期、按名称等选项。
- **Effort**: S

### 标签管理页空状态缺少引导
- **Page**: `/settings/tags`
- **Component**: 空状态
- **Issue**: 显示"暂无标签"，但没有"+ 创建标签"按钮或引导文案。用户不知道如何创建第一个标签。
- **Fix**: 添加空状态插图 + "创建你的第一个标签"按钮。
- **Effort**: S

### 家庭页信息过于简单，缺少家庭资产汇总
- **Page**: `/family`
- **Component**: 家庭页主体
- **Issue**: 只显示家庭名称、邀请码、成员列表（仅 1 人）。没有家庭总资产、人均资产、各成员资产占比等汇总信息。
- **Fix**: 添加家庭资产概览卡片（总资产、净资产、成员数）；成员卡片显示该成员持有资产数量。
- **Effort**: M

### 资产创建表单"同购入价"按钮默认禁用逻辑不清晰
- **Page**: `/assets/new`
- **Component**: 当前价值输入区
- **Issue**: "同购入价"按钮默认为 disabled 状态，但没有任何提示说明为什么禁用（需要先填购入价格才能启用）。用户可能困惑。
- **Fix**: 添加 tooltip 或 placeholder 提示"请先填写购入价格"；或在购入价格有值后自动启用并高亮。
- **Effort**: S

### 统计页数字格式不一致
- **Page**: `/stats`
- **Component**: 顶部汇总数字
- **Issue**: 统计页显示"¥63,040,503"（精确到元），而仪表盘显示"¥6304.05万"（万元缩写）。同一应用两种格式，视觉不一致。
- **Fix**: 统一使用万元缩写格式（超过 1 万时显示"X.XX万"），或提供用户可切换的格式选项。
- **Effort**: S

## P3 — Nice-to-Have

### 缺少儿童财商视角的可玩性元素
- **Page**: `/` (dashboard, "切换到孩子视角" button exists)
- **Component**: 孩子视角模式
- **Issue**: 顶部有"切换到孩子视角"按钮，但点击后的体验未知（未测试）。心愿单、资产列表等页面没有针对儿童的成就徽章、进度动画、积分反馈等元素。
- **Fix**: 孩子视角下：用大字体+emoji 替代数字；添加"存钱目标"进度条动画；达成心愿时有庆祝动效。
- **Effort**: L

### 负债高利率无视觉警示
- **Page**: `/liabilities`
- **Component**: 负债卡片
- **Issue**: 招商信用卡 18%、工商信用卡 15% 的高利率没有任何视觉警示（红色标记、警告图标等）。用户可能忽视高息负债的优先还款必要性。
- **Fix**: 利率 > 10% 时显示红色警示标签；添加"建议优先还款"提示。
- **Effort**: S

### 心愿单缺少与负债的联动提示
- **Page**: `/wishes`
- **Component**: 心愿卡片
- **Issue**: 用户有 ¥1554 万负债，同时有"买新车 ¥60 万"的高优先级心愿。没有任何提示建议先还高息负债再购置新资产。
- **Fix**: 当用户有高息负债时，在心愿单顶部显示"你有 X 笔高息负债，建议优先还清后再实现心愿"的温馨提示。
- **Effort**: M

### 仪表盘缺少骨架屏加载状态
- **Page**: `/`
- **Component**: 全页
- **Issue**: 页面加载时没有骨架屏，数据未到达前页面为空白或闪烁。
- **Fix**: 为总资产卡片、资产列表添加 Vant Skeleton 骨架屏。
- **Effort**: S

### AI 智能助手 Tab 无内容预览
- **Page**: Tab bar
- **Component**: "AI 智能助手" tab
- **Issue**: Tab bar 中有"AI 智能助手"入口，但未测试其内容。从 settings 页可见有 AI 配置入口，说明功能存在但可能未完全实现。
- **Fix**: 确保 AI 助手页有明确的空状态引导（"配置 API Key 开始使用"）而非空白页。
- **Effort**: S

### 乐观更新缺少竞态风险提示
- **Page**: 资产详情、负债详情
- **Component**: 编辑/还款操作
- **Issue**: 快速连续点击"出售资产"或负债"还款"按钮时，没有防重复提交的视觉反馈（按钮 loading 状态、禁用状态）。
- **Fix**: 操作按钮在请求进行中时显示 loading spinner 并禁用，防止重复提交。
- **Effort**: S
