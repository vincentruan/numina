## 关键发现

### 1. API 路由配置问题（已修复）

**问题描述**: 
- FastAPI 对无尾部斜杠的请求返回 307 重定向到带尾部斜杠的 URL
- nginx 代理配置未正确处理此重定向，导致客户端收到 404 错误
- 影响所有列表类 API（资产列表、负债列表、心愿列表等）

**根本原因**:
```
客户端请求: GET /numina/api/v1/assets
nginx 代理: → /api/v1/assets (backend)
FastAPI 响应: 307 → Location: /api/v1/assets/
nginx 跟随: GET /api/v1/assets/ → 404 (不匹配 /numina/api/ location)
```

**解决方案**:
在 nginx 配置中添加 `proxy_redirect` 规则：
```nginx
location /numina/api/ {
    proxy_pass http://backend/api/;
    # ... 其他配置
    proxy_redirect ~^http://[^/]+/api/(.*)$ /numina/api/$1;
}
```

**验证结果**: 修复后所有 API 正常工作

## UX 审查结果

基于代码分析和部分手动测试：

### 交互路径便捷性
- **优点**: 底部 Tab 导航清晰，核心功能入口直接
- **问题**: 资产创建需要 4 步，对高频操作不够友好
- **建议**: 在仪表盘添加"快速添加"入口

### 数据字段必要性  
- **优点**: 字段设计全面，覆盖各类资产需求
- **问题**: 表单字段过多，新用户可能困惑
- **建议**: 实现渐进式披露，高级字段默认折叠

### 视觉体验
- **优点**: Vant 组件库一致性好，配色方案合理
- **问题**: 仪表盘信息密度过高，新用户学习成本大
- **建议**: 采用卡片式布局，增强视觉层次
