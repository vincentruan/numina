# Numina 家庭资产管理系统验收计划

> 文档版本: 1.0
> 创建日期: 2026-03-19
> 验收目标: 确保系统功能完整、交互流畅、数据合理、视觉舒适、边界可控、安全可靠

---

## 一、验收目标

### 1.1 总体目标

Numina 作为家庭资产管理工具，需满足以下核心验收标准：

1. **功能完整性**: 所有业务功能正常运行，覆盖资产全生命周期管理
2. **交互便捷性**: 用户可快速完成常见操作，路径清晰直观
3. **数据必要性**: 字段设计合理，无冗余，输入负担最小化
4. **视觉体验**: 界面美观舒适，信息层级清晰
5. **边界可控性**: 异常情况处理得当，不崩溃、不丢失数据
6. **安全性**: 认证授权正确，数据隔离严格，无安全漏洞

### 1.2 验收范围

| 模块 | 功能点 |
|------|--------|
| 认证 | 注册、登录、Token刷新、加入家庭 |
| 资产 | CRUD、估值更新、出售、退役、归档 |
| 负债 | CRUD、还款记录、自动结清 |
| 仪表盘 | 概览、配置、趋势、排行、低使用率、收益率 |
| 家庭 | 成员管理、角色权限、邀请码 |
| 心愿单 | CRUD、心愿兑现 |
| 分类/标签 | 分类管理、标签管理 |
| 活动 | 操作日志记录 |

## 五、验收执行计划

### 5.1 验收流程

```
1. 功能测试 (2小时)
   - 按测试场景清单逐项执行
   - 记录通过/失败状态
   - 标注发现的Bug

2. 截图存档 (1小时)
   - 按截图清单逐页截图
   - 标注截图时间和环境
   - 整理为PDF报告

3. UX审查 (1小时)
   - 按检查清单逐项评审
   - 记录优化建议
   - 区分必须修复/建议优化

4. 安全检查 (30分钟)
   - 执行安全测试场景
   - 检查日志和数据库
   - 验证权限控制

5. 报告整理 (30分钟)
   - 汇总测试结果
   - 列出Bug清单
   - 给出验收结论
```

### 5.2 验收结论标准

| 等级 | 标准 |
|------|------|
| 通过 | 所有功能场景通过，无安全漏洞，UX问题≤3个 |
| 条件通过 | 核心功能通过，非关键Bug≤5个，需限期修复 |
| 不通过 | 核心功能异常，或存在安全漏洞，或关键Bug>5个 |

### 5.3 Bug优先级定义

| 优先级 | 定义 | 示例 |
|--------|------|------|
| P0-阻塞 | 核心功能不可用，阻塞验收 | 无法登录、数据丢失 |
| P1-严重 | 主要功能异常，影响使用 | 资产创建失败、图表不显示 |
| P2-一般 | 次要功能异常，有替代方案 | 筛选不工作、提示文案错误 |
| P3-建议 | 体验优化，不影响功能 | UI细节、文案优化 |
