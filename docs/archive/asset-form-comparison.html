优化建议（按优先级排序）
P0 分类选择器改为图标网格 — 21 个分类带 emoji，网格布局让扫描速度远快于文字列表。直接影响首页分类筛选视觉一致性。
P0 预期寿命单位改为"年" — 用户思维是"用 3 年"，不是"1095 天"。后端存天数不变，前端用年输入并自动换算。
P0 当前价值添加"同购入价"快捷按钮 — 约 70% 新购资产当前价值=购入价，一键消除重复输入。
P1 图片区域提升视觉权重 — 顶部独立大图区域 120px 居中，增加拍照意愿，资产识别度更高。
P1 使用频率改为图标按钮组 — 5 个互斥选项同时可见，无需展开 Picker，交互更直观。
P1 状态字段移到编辑模式 — 录入时隐藏（默认服役中），编辑时才显示，减少录入噪音。
P1 新增标签字段 — 多选标签选择器，支持统计页按标签聚合（如"旅行装备"标签）。
P2 新增资产类型字段 — SegmentedControl 选择实物/金融资产，金融资产隐藏实物属性字段（预期寿命、使用频率等）。
P2 预期寿命添加"不限"选项 — 某些资产无明确预期寿命（如房产），提供快捷选项。
总览/统计场景关联性优化
分类图标网格 → 首页分类筛选 — 录入时的图标选择，直接作为首页快速筛选入口，视觉一致性强化。
使用频率 → 低使用率预警 — 录入时填的频率，直接驱动"闲置资产"统计模块，提升资产盘点意识。
预期寿命（年） → 资产到期提醒 — 统计页展示"即将到期资产"列表，提前预警置换需求。
标签 → 自定义统计维度 — 用户可按标签查看资产分布，比固定分类更灵活，满足个性化聚合需求。
"同购入价" → 收益率基准 — 当前价值与购入价关系准确记录，直接影响统计页收益率计算准确性。
