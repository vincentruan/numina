# 资产录入界面优化实施计划

> 基于参考设计（有数 App）与当前实现的深度对比分析

## 优先级定义

| 优先级 | 定义 | 原则 |
|--------|------|------|
| P0 | 必须做 | 用户体验显著提升，实施成本低 |
| P1 | 应该做 | 完善功能，提升一致性 |
| P2 | 可以做 | 增值功能，时间允许时实施 |

---

## P0 优化项（必须做）

### OP-001: 分类选择器改为图标网格

**现状问题**：当前使用下拉 Picker（文字列表），丢失 emoji 视觉锚点，选择效率低。

**目标**：图标网格布局，一屏看全，点击直接选择。

**改动范围**：
- 前端组件：`AssetForm.vue`
- 新增组件：`CategoryGrid.vue`（图标网格选择器）
- 后端：无改动

**验收标准**：
1. 分类以图标网格形式展示，每个分类显示 emoji + 名称
2. 当前选中项有高亮边框/背景
3. 点击图标直接选中，无需二次确认
4. 横向滚动支持（超过一屏的分类）
5. 与首页分类筛选视觉一致

**实施步骤**：
1. 创建 `CategoryGrid.vue` 组件
2. 接收 `categories` props 和 `selected` 状态
3. 实现 grid 布局 + emoji 显示 +选中态
4. 替换 `AssetForm.vue` 中的分类 Picker
5. 测试移动端滚动和点击交互

---

### OP-002: 预期寿命单位改为"年"

**现状问题**：当前单位为"天"，用户心智模型是"用 3 年"，认知负担高。

**目标**：前端显示"年"，后端存储天数不变，自动换算。

**改动范围**：
- 前端组件：`AssetForm.vue`
- 前端逻辑：年→天换算（提交时），天→年换算（编辑回显时）
- 后端：无改动（继续存天数）
- 数据库：无改动

**验收标准**：
1. 输入框显示单位"年"，placeholder "请输入预期使用年限"
2. 提交时：`expected_life_years * 365 = expected_life_days`
3. 编辑回显时：`expected_life_days / 365 = expected_life_years`（向下取整）
4. 添加"不限"快捷选项（对应 `null` 或 `999999`）
5. 输入验证：1-100 年范围

**实施步骤**：
1. `AssetForm.vue` 新增 `expected_life_years` 计算属性
2. 提交时换算为 `expected_life_days`
3. 编辑模式下反向换算回显
4. 添加"不限"按钮（设置特殊值或 null）
5. 测试新建/编辑场景换算正确性

---

### OP-003: 当前价值添加"同购入价"快捷按钮

**现状问题**：约 70% 新购资产当前价值 = 购入价，需重复输入。

**目标**：一键同步购入价到当前价值。

**改动范围**：
- 前端组件：`AssetForm.vue`
- 后端：无改动

**验收标准**：
1. 当前价值字段右侧显示"同购入价"按钮
2. 点击按钮，`current_value = purchase_price`
3. 购入价未填写时，按钮禁用或隐藏
4. 按钮样式：次要按钮，不抢视觉焦点
5. 点击后当前价值字段显示同步后的值，可手动修改

**实施步骤**：
1. `AssetForm.vue` 当前价值字段右侧添加快捷按钮
2. 实现 `syncPurchasePrice()` 方法
3. 购入价变化时，按钮禁用状态联动
4. 测试按钮点击逻辑和值同步

## P1 优化项（应该做）

### OP-004: 图片区域提升视觉权重

**现状问题**：图片嵌入表单行，80px 左对齐，视觉权重低。

**目标**：顶部独立大图区域，120px 居中，增加拍照意愿。

**改动范围**：
- 前端组件：`AssetForm.vue`
- CSS 样式调整

**验收标准**：
1. 图片区域移到表单顶部，独立展示
2. 图片尺寸 120×120px，居中显示
3. 无图片时显示相机图标 + "点击添加图片"文字
4. 有图片时显示预览，点击可更换/删除
5. 视觉权重明显高于其他字段

**实施步骤**：
1. 调整 `AssetForm.vue` 模板结构，图片区域移到顶部
2. 调整 CSS 样式，增大尺寸和居中对齐
3. 优化 placeholder 样式
4. 测试移动端展示效果

---

### OP-005: 使用频率改为图标按钮组

**现状问题**：下拉 Picker，5 个选项不可同时可见，交互层级深。

**目标**：横向图标按钮组，一目了然，点击直接选中。

**改动范围**：
- 前端组件：`AssetForm.vue`
- 新增数据：使用频率选项图标定义

**验收标准**：
1. 5 个选项以图标按钮组展示：每天/每周/每月/偶尔/闲置
2. 每个选项有图标 + 文字
3. 选中态有填充色高亮
4. 点击直接切换选中，无需二次确认
5. 响应式布局，小屏幕可滚动

**实施步骤**：
1. 定义使用频率选项数据（icon + label + value）
2. `AssetForm.vue` 替换 Picker 为按钮组
3. 实现选中态切换逻辑
4. 测试交互效果

---

### OP-006: 状态字段移到编辑模式

**现状问题**：录入时显示状态字段，99% 新资产是"服役中"，是噪音。

**目标**：录入时隐藏状态（默认"服役中"），编辑时才显示。

**改动范围**：
- 前端组件：`AssetForm.vue`
- 后端：无改动（新建时默认 status="服役中"）

**验收标准**：
1. 新建资产时，状态字段不显示
2. 后端新建接口默认 status="服役中"
3. 编辑资产时，状态字段正常显示并可修改
4. 编辑模式可通过 props 区分

**实施步骤**：
1. `AssetForm.vue` 根据 `isEdit` 条件渲染状态字段
2. 确认后端新建接口默认值
3. 测试新建/编辑场景

---

### OP-007: 新增标签字段

**现状问题**：功能缺失，统计页无法按标签聚合。

**目标**：多选标签选择器，支持自定义标签。

**改动范围**：
- 前端组件：`AssetForm.vue`
- 新增组件：`TagSelector.vue`
- 后端 API：新增标签 CRUD 接口
- 数据库：新增 `tags` 表 + `asset_tags` 关联表

**验收标准**：
1. 标签字段显示已选标签 + "添加标签"按钮
2. 点击添加弹出标签选择器，可多选
3. 支持创建新标签
4. 标签数据持久化
5. 统计页可按标签筛选资产

**实施步骤**：
1. 数据库：创建 `tags` 表 + `asset_tags` 关联表
2. 后端：标签 CRUD API + 资产关联标签 API
3. 前端：`TagSelector.vue` 组件
4. `AssetForm.vue` 集成标签字段
5. 统计页集成标签筛选功能

## 总览/统计关联性优化

### DS-001: 分类图标网格 → 首页分类筛选

**原则**：录入时的图标选择，直接作为首页快速筛选入口。

**实施**：
- 首页筛选组件复用 `CategoryGrid.vue` 样式
- 选中态视觉一致

---

### DS-002: 使用频率 → 低使用率预警

**原则**：录入时填的频率，直接驱动"闲置资产"统计模块。

**实施**：
- 统计页新增"闲置资产"卡片
- 频率="闲置"的资产聚合展示
- 提醒用户盘点或处置

---

### DS-003: 预期寿命（年） → 资产到期提醒

**原则**：统计页展示"即将到期资产"列表。

**实施**：
- 统计页新增"即将到期"卡片
- 计算剩余寿命：`购入日期 + 预期寿命 - 当前日期`
- 剩余寿命 < 30 天的资产预警

---

### DS-004: 标签 → 自定义统计维度

**原则**：用户可按标签查看资产分布。

**实施**：
- 统计页新增"按标签查看"入口
- 标签选择后，资产列表按标签过滤

---

### DS-005: "同购入价" → 收益率基准

**原则**：当前价值与购入价关系准确记录。

**实施**：
- 统计页收益率计算：`(当前价值 - 购入价) / 购入价`
- 数据准确性依赖录入时的正确同步
