> 基于 superpowers:brainstorming 技能的深度思考分析

## 一、参考界面第一性原理分析（有数 App）

### 1.1 图片区域（顶部大图 120px 居中独立）

**设计意图**：
- 视觉锚点：图片是资产最直观的识别方式，大尺寸突出视觉权重
- 拍照动机：独立区域暗示"拍照很重要"，提升用户拍照意愿
- 快速预览：录入时即可看到资产全貌，降低认知负担

**第一性原理**：
> 资产的本质是"物品"，物品的视觉特征（外观、颜色、形状）是人类识别物品的主要方式。
> 图片区域的设计应该最大化视觉识别效率，而不是作为"表单字段"之一。

**统计关联**：
- 首页资产卡片有图片，录入时图片质量直接影响首页展示效果
- 数据统计页如果有分类分布图，图片可作为图标来源

---

### 1.2 资产类型（SegmentedControl 分段控件）

**设计意图**：
- 高频决策：资产类型只有 2 个值（实物/金融），用户需要一眼看全
- 直接点击：无需展开，点击即选中，交互效率最高
- 视觉明确：选中态用填充色，未选中态用无填充，对比强烈

**第一性原理**：
> 用户心智模型：实物资产（手机、手表）vs 金融资产（存款、股票）。
> 这两种资产的属性差异显著：实物有预期寿命、使用频率；金融有利率、到期日。
> 类型选择是"分岔路口"，决定了后续字段分支。分岔路口应该在路径起点最显眼的位置。

**统计关联**：
- 首页总览可以按资产类型分组展示（实物资产总价值 vs 金融资产总价值）
- 数据统计页可以展示"实物资产日均成本 vs 金融资产收益率"对比

**当前实现差距**：
- 当前用下拉 Picker，交互步骤多 2 次（点击 → 弹出 → 选择 → 确认）
- 类型字段在表单中间位置，而非视觉焦点

---

### 1.3 分类选择（图标网格）

**设计意图**：
- 视觉锚点：21 个分类带 emoji，图标是视觉识别的首要元素
- 一屏看全：网格布局让用户扫描速度远快于文字列表
- 快速选择：点击图标直接选中，无需二次确认

**第一性原理**：
> 分类是"类别"，类别是人类认知物品的基本方式。
> 类别的视觉化（图标）比文字化（列表）效率高 3-5 倍（人类视觉识别速度 vs 文字识别速度）。
> 分类选择应该是"视觉扫描 → 点击"，而不是"文字扫描 → 点击 → 确认"。

**统计关联**：
- 首页分类筛选可以直接使用相同的图标网格（视觉一致性）
- 数据统计页的"资产分布饼图"，每个扇形可以用分类图标标注
- Dashboard 的分类分组视图，分类图标作为分组标题

**当前实现差距**：
- 当前用下拉 Picker（文字列表），丢失 emoji 视觉锚点
- 分类选择效率大幅下降（需要点击 → 弹出 → 文字扫描 → 选择 → 确认）

---

### 1.4 当前价值（"同购入价"快捷按钮）

**设计意图**：
- 常见场景：约 70% 新购资产当前价值 = 购入价
- 效率优化：一键消除重复输入
- 用户心智：用户期望"刚买的手机，价值就是买的价格"

**第一性原理**：
> 用户录入资产的场景：刚买了一台手机，想记录。
> 用户心智：购入价格 = 5999，当前价值应该也是 5999（刚买的，没贬值）。
> 系统要求输入两次相同的数字，是对用户心智的违背。

**统计关联**：
- 收益率计算：`(当前价值 - 购入价) / 购入价`
- 如果用户录入时当前价值不准确，收益率计算就失真
- 数据统计页的"资产收益率"依赖准确的当前价值

**当前实现差距**：
- 无快捷按钮，用户需手动重复输入
- 录入效率下降，数据准确性下降（用户可能懒得填当前价值）

---

### 1.5 预期寿命（单位"年" + "不限"选项）

**设计意图**：
- 用户心智：用户说"这个手机用 3 年"，不说"用 1095 天"
- 认知减负：用年作为单位，符合用户心智模型
- 特殊场景：某些资产（房产、收藏品）无明确预期寿命，"不限"选项解决

**第一性原理**：
> 用户对"使用寿命"的认知是年，不是天。
> 系统存储天数是为了计算精确（日均成本），但前端显示应该符合用户心智。
> "不限"选项解决"无预期寿命"的特殊场景，避免用户被迫填写不准确的数字。

**统计关联**：
- 资产到期提醒：统计页可以展示"即将到期资产"列表
- 剩余寿命计算：`购入日期 + 预期寿命 - 当前日期`
- 如果单位是天，用户填写不准确的数字，到期提醒就失真

**当前实现差距**：
- 单位是"天"，用户心智模型不匹配
- 无"不限"选项，某些资产被迫填写不准确数字

---

### 1.6 使用频率（图标按钮组）

**设计意图**：
- 互斥单选：5 个选项，用户需要直观对比
- 一屏看全：所有选项同时可见，无需展开
- 快速选择：点击即选中，交互效率最高

**第一性原理**：
> 使用频率是"使用模式"的抽象，用户需要对比所有选项才能做出决策。
> "每天用"vs"偶尔用"的差异，用户需要看到所有选项才能判断。
> 图标辅助识别（每天=📅，每周=📆），比纯文字效率更高。

**统计关联**：
- 闲置资产预警：统计页可以展示"闲置资产"列表
- 使用频率分布：数据统计页可以展示"使用频率分布饼图"
- 日均成本修正：高频率使用的资产，日均成本更有意义

**当前实现差距**：
- 用下拉 Picker，所有选项不可同时可见
- 交互层级深（点击 → 弹出 → 选择 → 确认）
- 丢失图标辅助识别

---

### 1.7 标签（多选标签选择器）

**设计意图**：
- 横切聚合：标签是跨分类的聚合维度（如"旅行装备"标签）
- 自定义维度：用户可以自定义聚合方式，比固定分类更灵活
- 多选支持：一个资产可以属于多个标签

**第一性原理**：
> 分类是"系统定义的类别"，标签是"用户定义的类别"。
> 用户对资产的认知维度是多元的：分类（数码）+ 标签（旅行装备 + 工作必备）。
> 标签是用户的个性化组织方式，系统应该支持。

**统计关联**：
- 首页筛选：用户可以按标签筛选资产（比分类筛选更灵活）
- 数据统计页：用户可以按标签查看资产分布
- 自定义报表：标签可以作为报表的自定义维度

**当前实现差距**：
- 标签字段存在（数据库有 `asset_tags` 关联表），但录入界面未展示
- 用户无法在录入时添加标签，只能在编辑时添加

---

### 1.8 状态字段（录入时不显示）

**设计意图**：
- 默认值：新录入资产 99% 是"服役中"
- 噪音减负：录入时不需要用户选择状态，减少录入噪音
- 编辑时可见：状态变化（退役、出售）在编辑时才需要选择

**第一性原理**：
> 新录入资产的场景：刚买了一台手机，想记录。
> 用户心智：这台手机在用（服役中），不需要我告诉系统。
> 状态字段在录入时是噪音，应该隐藏。

**统计关联**：
- Dashboard 状态汇总（服役中/闲置/已出售/已退役）
- 录入时默认"服役中"，确保状态汇总数据准确

**当前实现差距**：
- 状态字段在录入时显示，增加录入噪音
- 用户被迫选择"服役中"，违背用户心智

## 二、总览/统计场景深度关联性分析

### 2.1 Dashboard（首页总览）

**当前实现特点**：
- NetWorthCard：净资产、总资产、总负债、日均成本
- StatusSummaryGrid：状态汇总（服役中/闲置/已出售/已退役）
- 分类分组视图：按分类分组展示资产列表
- 标签筛选：支持按标签筛选资产

**关联性优化方向**：

| 录入字段 | Dashboard 关联 | 优化建议 |
|---------|---------------|---------|
| 分类图标网格 | 分类分组视图的图标标题 | 视觉一致性强化 |
| 使用频率 | 闲置资产预警卡片 | 新增"闲置资产"汇总入口 |
| 预期寿命（年） | 资产到期提醒 | 新增"即将到期"汇总入口 |
| 标签 | 标签筛选入口 | 已有，但录入时无法添加标签 |
| 资产类型 | 按类型分组展示 | 新增"实物/金融"分组视图 |

**新增建议**：
1. **闲置资产卡片**：使用频率="闲置"的资产聚合展示，提醒用户盘点
2. **即将到期卡片**：剩余寿命 < 30 天的资产预警
3. **资产类型分组**：实物资产 vs 金融资产分组视图（日均成本 vs 收益率）

---

### 2.2 DataStatsPage（数据统计）

**当前实现特点**：
- Summary Cards：总资产、总负债、净资产
- TrendLineChart：资产趋势曲线
- AllocationPieChart：资产分布饼图
- Quick Stats：资产数量、本月新增、日均成本

**关联性优化方向**：

| 录入字段 | 统计关联 | 优化建议 |
|---------|---------|---------|
| 分类图标网格 | 资产分布饼图图标标注 | 每个扇形用分类图标标注 |
| 使用频率 | 使用频率分布饼图 | 新增"使用频率分布"图表 |
| 预期寿命（年） | 资产到期曲线 | 新增"资产到期预测"图表 |
| 标签 | 按标签分布图 | 新增"标签分布"图表 |
| 资产类型 | 类型对比图 | 新增"实物 vs 金融"对比图 |
| 当前价值 | 收益率分布 | 新增"资产收益率"统计 |

**新增建议**：
1. **使用频率分布饼图**：每天/每周/每月/偶尔/闲置的资产占比
2. **资产到期预测图**：按年份展示即将到期的资产数量
3. **标签分布图**：用户自定义标签的资产分布
4. **收益率统计**：资产收益率排名（当前价值 vs 购入价）

## 四、验收标准

### 4.1 录入界面验收

| 检查项 | 标准 |
|--------|------|
| 图片区域 | 顶部独立区域，120px 居中，有相机图标 + "点击添加图片"文字 |
| 资产类型 | SegmentedControl，实物/金融资产两个选项，选中态填充色 |
| 分类选择 | 图标网格，21 个分类带 emoji，选中态边框高亮，点击直接选中 |
| 当前价值 | 有"同购入价"快捷按钮，点击同步购入价，购入价未填时禁用 |
| 预期寿命 | 单位"年"，有"不限"选项，输入验证 1-100 年 |
| 使用频率 | 图标按钮组，5 个选项带图标，选中态填充色，点击直接选中 |
| 标签 | 多选标签选择器，支持添加新标签 |
| 状态字段 | 录入时不显示（默认"服役中"），编辑时显示 |

### 4.2 Dashboard 验收

| 检查项 | 标准 |
|--------|------|
| 分类分组视图 | 分类图标作为分组标题，与录入界面一致 |
| 闲置资产卡片 | 使用频率="闲置"的资产聚合展示，点击跳转筛选 |
| 即将到期卡片 | 剩余寿命 < 30 天的资产预警，点击跳转筛选 |

### 4.3 统计页验收

| 检查项 | 标准 |
|--------|------|
| 资产分布饼图 | 每个扇形用分类图标标注 |
| 使用频率分布图 | 每天/每周/每月/偶尔/闲置的占比饼图 |
| 资产到期预测图 | 按年份展示即将到期的资产数量曲线 |
