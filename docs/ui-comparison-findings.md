## ❌ 发现的UI差异和问题

### 问题1: 选择模式计数器不更新 ⚠️ NEW
- **严重程度**: HIGH
- **描述**: 在选择模式下，点击资产卡片的复选框后，顶部的「已选 N 项」计数器不更新
- **当前表现**:
  - 点击复选框后，计数器始终显示「已选 0 项」
  - 复选框视觉上没有选中状态变化
- **预期表现**: 点击复选框后，计数器应该实时更新为「已选 1 项」「已选 2 项」等
- **影响**: 用户无法知道已选择了多少个资产
- **文件位置**: frontend/src/pages/DashboardPage.vue
- **可能原因**:
  - 复选框点击事件处理逻辑有问题
  - selectedIds数组未正确更新
  - 之前修复的数组mutation bug可能引入了新问题

### 问题2: 重复的Tesla Model 3资产 ✅ FIXED
- **严重程度**: MEDIUM
- **描述**: 列表中显示了两个Tesla Model 3，一个显示"未分类"，一个显示"车辆"
- **状态**: 已修复 - 删除了未分类的重复资产
- **修复操作**: 通过API删除了ID为 89daf790-9fdb-4e6f-85de-6043bbc1e38c 的重复资产

### 问题3: 分类导航栏未显示
- **严重程度**: LOW
- **描述**: 参考截图中有分类导航栏（如"MR专栏"），但当前实现中未看到
- **当前表现**: 状态Tab下方直接是资产列表
- **预期表现**: 应该有分类导航栏（当有多个分类时显示）
- **可能原因**:
  - 当前用户只有系统默认分类，没有自定义分类
  - 或者分类导航栏的显示条件未满足（需要多个分类才显示）

### 问题4: 选择模式复选框覆盖层位置 ⚠️ NEEDS VERIFICATION
- **严重程度**: MEDIUM
- **描述**: 需要确认选择模式下复选框覆盖层是否在卡片左上角正确位置
- **当前表现**: 复选框显示在资产卡片上，但具体位置需要视觉确认
- **预期表现**: 复选框应该在卡片左上角（距离边缘8px），有白色半透明背景和圆形阴影
- **参考**: docs/images/references/有数app-首页-选择.jpeg
