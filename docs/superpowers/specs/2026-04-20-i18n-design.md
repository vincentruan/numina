# Internationalization Design

**Date:** 2026-04-20
**Status:** Approved
**Scope:** 国际化系统，支持多语言界面

---

## Problem

系统仅支持中文界面，非中文用户难以使用。国际化扩展时需要全局修改，缺乏统一的翻译 Key 命名规范，导致翻译混乱和重复。

---

## Goals

1. 支持多语言界面（zh-CN、en-US）
2. 定义统一的翻译 Key 命名规范
3. 实现本地化格式（日期、货币）
4. 便于未来扩展更多语言

---

## Architecture

### i18n 结构

```
frontend/src/i18n/
├── index.ts           # i18n 实例配置
└── locales/
    ├── zh-CN.ts       # 简体中文翻译
    └── en-US.ts       # 英文翻译
```

使用 vue-i18n 提供翻译服务，语言选择存储在 localStorage。

### 本地化流程

```
用户选择语言 → localStorage 存储 → vue-i18n 切换 locale → 
所有组件重新渲染（使用新语言） → 日期/货币格式本地化
```

### i18n 实例配置

```typescript
// frontend/src/i18n/index.ts
import { createI18n } from 'vue-i18n'
import zhCN from './locales/zh-CN'
import enUS from './locales/en-US'

const i18n = createI18n({
  legacy: false,
  locale: localStorage.getItem('locale') || 'zh-CN',
  fallbackLocale: 'zh-CN',
  messages: {
    'zh-CN': zhCN,
    'en-US': enUS
  }
})

export default i18n
```

### 本地化格式

**日期格式**

| 类型 | zh-CN | en-US |
|------|-------|-------|
| 完整日期 | 2026年4月20日 | Apr 20, 2026 |
| 时间戳 | 2026-04-20 10:30:00 | Apr 20, 2026 10:30:00 |
| 月份 | 2026年4月 | April 2026 |

实现（使用 dayjs）：

```typescript
import dayjs from 'dayjs'
import 'dayjs/locale/zh-cn'
import 'dayjs/locale/en'

const format = {
  'zh-CN': {
    fullDate: (date: Date) => dayjs(date).locale('zh-cn').format('YYYY年M月D日'),
    timestamp: (date: Date) => dayjs(date).locale('zh-cn').format('YYYY-MM-DD HH:mm:ss')
  },
  'en-US': {
    fullDate: (date: Date) => dayjs(date).locale('en').format('MMM D, YYYY'),
    timestamp: (date: Date) => dayjs(date).locale('en').format('MMM D, YYYY HH:mm:ss')
  }
}
```

**货币格式**

| 类型 | zh-CN | en-US |
|------|-------|-------|
| 人民币 | ¥1,234.56 | ¥1,234.56 |
| 美元 | $1,234.56 | $1,234.56 |

货币符号与语言无关，取决于币种本身。

### 语言切换实现

```vue
<!-- SettingsPage.vue -->
<script setup lang="ts">
import { useI18n } from 'vue-i18n'

const { locale } = useI18n()

const languages = [
  { code: 'zh-CN', name: '简体中文' },
  { code: 'en-US', name: 'English' }
]

function changeLanguage(code: string) {
  locale.value = code
  localStorage.setItem('locale', code)
  // 刷新页面以应用所有更改
  window.location.reload()
}
</script>

<template>
  <van-cell-group>
    <van-cell 
      title="语言" 
      :value="languages.find(l => l.code === locale)?.name"
      @click="showPicker = true"
    />
  </van-cell-group>
  
  <van-popup v-model:show="showPicker">
    <van-picker 
      :columns="languages.map(l => l.name)"
      @confirm="onConfirm"
    />
  </van-popup>
</template>
```
