# 日历功能 UI 优化设计

**日期：** 2026-04-23
**范围：** `frontend/src/components/calendar/ChildCalendar.vue` + `ChildDayDetailPage.vue`
**目标：** 用视觉密度表达活动丰富度，同时保留事件类型区分，兼顾儿童和父母两种视角。

---

## 核心设计原则

- **视觉密度 = 活动总量**：格子背景色深浅反映当天完成事件总数
- **圆点 = 事件构成**：三色圆点区分打卡/心愿/成就类型
- **两层信息互补**：热力背景回答"今天有多忙"，圆点回答"做了什么"

---

## 第一节：格子视觉层次

### 热力背景色阶

| 总活动数 | 背景色    | 色值      |
|---------|----------|-----------|
| 0       | 白色      | `#ffffff` |
| 1       | 极浅橙    | `#fff3e0` |
| 2–3     | 浅橙      | `#ffe0b2` |
| 4–6     | 中橙      | `#ffb74d` |
| 7+      | 深橙（品牌色）| `#f5a623` |

总活动数 = `chore_count + wish_count + milestone_count`。

### 今日高亮

日期数字保持橙色圆形背景（现有逻辑）。格子背景色仍按热力色阶走，不被今日样式覆盖。

### 类型圆点调整

- 圆点尺寸：5px → **6px**
- 当格子背景色为中橙/深橙（4+ 活动）时，圆点加 `1px white` 描边，防止与背景融合

### 多事件数字角标

同类事件超过 1 个时，圆点右上角显示数字：

```
单个：  [绿点]
多个：  [绿点⁴]  （右上角 8px 数字，同色系）
10+：  [绿点⁹⁺]
```

格子底部 `day-dots` 区域最大高度约 14px，不撑破格子。

### 视角差异

| 属性 | 儿童视角 | 父母视角 |
|------|---------|---------|
| 格子圆角 | 10px（圆润活泼）| 8px（规整）|
| 热力色阶 | 相同 | 相同 |

## 第二节：触摸友好性

### 点击区域修复

**问题：** `gap: 2px` 切割格子边缘，导致边缘点击区域不连续。

**修复：**
```css
/* 改前 */
.cal-grid { gap: 2px; }

/* 改后 */
.cal-grid { gap: 0; }
.cal-cell { padding: 1px; }
```

视觉间距保持不变，点击区域连续。

### 按钮尺寸

月份切换按钮：32px → **44px**（符合 iOS HIG 最小触摸目标）。

### 点击反馈

```css
/* 改前 */
.cal-cell.active:active { background: #f0f0f0; }

/* 改后 */
.cal-cell.active:active { transform: scale(0.92); }
```

`scale` 反馈比背景色变化更有手感，且不与热力背景色冲突。

### 加载状态

切换月份时无 spinner，改为：
```css
.cal-grid.loading {
  opacity: 0.4;
  pointer-events: none;
  transition: opacity 0.2s;
}
```
加载完成后淡入，避免布局跳动。

## 第三节：扩展方向

### 近期值得做

**1. 月份统计条**
日历下方一行文字摘要：
```
本月打卡 23次 · 心愿实现 2个 · 成就 1个
```
父母视角额外显示：`完成率 76%`

数据从现有 `days` 数组前端聚合，零后端改动。

**2. 连续打卡条纹**
连续有打卡的日期之间画 1px 橙色细线（`position: absolute`），形成视觉"连击链"。
后端已有 `streak_count` 字段，前端纯计算，无需新 API。

**3. 父母视角多孩子对比**
"全部"tab 选中时，格子内显示多孩子圆点（每孩子一色，最多 3 个）。
超过 3 个孩子退化为单色热力图。

### 不做（YAGNI）

- 周视图 — 信息密度不足，日历已够用
- 事件编辑 — 日历只读，编辑走原有页面
- 推送提醒 — 超出当前系统能力边界

## 实施优先级

| 优先级 | 改动 | 复杂度 |
|-------|------|-------|
| P0 | 热力背景色阶 | 低（纯 CSS + computed）|
| P0 | 触摸区域修复（gap→padding）| 低 |
| P0 | 按钮 44px + scale 反馈 | 低 |
| P1 | 圆点数字角标 | 低-中 |
| P1 | 加载状态 opacity | 低 |
| P2 | 月份统计条 | 低 |
| P2 | 连续打卡条纹 | 中 |
| P3 | 多孩子对比 | 中-高 |
