## P1 — Major UX Issues

### 1. Liability type shows raw enum `consumer_loan` instead of localized label

- **Page**: `/liabilities`
- **Component**: Liability card category badge
- **Issue**: Three liabilities show `consumer_loan` as the category label (消费贷装修, 花呗, 京东白条) instead of a localized Chinese label like "消费贷" or "个人贷款". This exposes internal implementation detail to users.
- **Fix**: Map `consumer_loan` to a display label in the liability card component or ensure the category system provides translated names. Check `liabilityTypeLabel()` utility or i18n mapping.
- **Effort**: S

## P2 — Minor Polish

### 1. ~~Child coin balance displays tier number instead of total coins~~ NOT A BUG

- **Page**: `/child/` (ChildHomePage), `/child/tasks`, `/child/ledger`
- **Component**: `CoinDisplay` component with `splitCoinTiers()`
- **Issue**: Initially appeared that `★ 2` was showing a tier number instead of actual balance (200). Investigation confirmed this is **working as designed** — the `CoinDisplay` component uses a gold/silver/copper tier system (10:1 ratios) as gamification. 200 coins = 2 gold coins, displayed as `★ 2`. The wishes page shows raw `star_coin_cost` (200) separately, which is a different display intent.
- **Status**: Not a bug — closed

### 2. Child treasures page shows empty state despite seed data existing

- **Page**: `/child/treasures`
- **Component**: Treasures/blind-box list
- **Issue**: Shows "还没有宝贝，快去完成家务赚星星币吧！" empty state. The seed data includes blind box gifts in the pool, but 小宝 may not have any draws yet. This is expected behavior, not a bug — but the empty state message could guide the child to try the blind box draw rather than just mentioning chores.
- **Fix**: Consider adding a CTA button to draw from the blind box pool if bonus draws are available. Low priority.
- **Effort**: S
