## 失败详情

### C2.3 — 心愿详情页 (afford bar 净资产显示异常)
- **路由**: http://localhost:5173/wishes/1828100970479681
- **截图**: dogfood-output/c2.3-wish-detail.png
- **预期表现**: afford bar 应显示"当前净资产 ¥465.58万" (与 Dashboard 一致)
- **当前错误表现**: afford bar 显示"当前净资产 ¥0.00，暂不足" — 净资产为 0
- **初步判断**: useAffordBar composable 获取家庭净资产的 API 调用可能返回 0 或失败; 建议检查 useAffordBar.ts 中 net worth 的数据源 (是否调用了 /dashboard/overview 或 /family/net-worth 接口; 是否存在 cookie auth 未携带导致 401 的情况)

### C3.2 — AI 对话 — 发送消息后陷入思考循环
- **路由**: http://localhost:5173/ai/chat
- **截图**: dogfood-output/c3.2-ai-chat-stuck.png
- **预期表现**: 发送消息后 AI 逐步流式返回回答，60s 内完成
- **当前错误表现**: AI 回复重复 "Let me check what data and resources are available for this family asset query." 等文本，`review_skill_package` 工具调用失败 (ValueError: Local review targets must be .skill archives or directories containin...)。底部显示 "Agent 正在控制 ⏹ 中断" 按钮持续 60s+，未产生有效回答
- **初步判断**: AI agent 的 numina skill 中配置了 `review_skill_package` 工具，但该工具在非 .skill archive 环境下失败; AI 陷入重试循环。建议检查 numina app 的 agent skill 配置，移除或修复 review_skill_package 工具; 或检查 agent 的 system prompt 中是否有不必要的 skill review 指令

## 已知/确认的设计出入 (Design Divergences)

### C4.0 — 币种切换 — 逐条记录不换算 (Confirmed Bug Class)
- **行为**: 切换 default_currency 从 CNY → USD 后:
  - Dashboard 聚合值正确换算: ¥465.58万 → ¥68.91万 (server-side conversion via exchange rate)
  - 资产列表逐条记录仍显示原始 CNY 值: ¥350.00万, ¥420.00万 等 (NOT converted)
- **状态**: 此为已知 bug class，已确认 — 逐条记录页面不做汇率换算，仅显示记录原始币种金额
- **建议**: 如需修复，需在资产/负债/心愿列表前端对 `currency !== default_currency` 的记录做客户端汇率换算
