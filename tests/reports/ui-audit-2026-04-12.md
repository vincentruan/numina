# Numina UI/UX Audit — 2026-04-12

## P1 Issues (High Impact)

1. **`--text-tertiary` contrast failure** (~2.5:1 vs 4.5:1 required)
   - Token: `#3c3c4399` (60% opacity on white) ≈ `#9a9a9e`
   - Fix: Change to solid `#6e6e73` (≥4.5:1 on white)
   - Affects: All pages (secondary labels, timestamps, helper text)

2. **No list virtualization** — 85 assets in single DOM list
   - Fix: Use `vue-virtual-scroller` or Vant virtual list
   - Affects: `/assets`, Dashboard asset list

3. **Emoji as functional icons**
   - `UsageFreqSelector`: `📅📆🗓️💤📦` as frequency selector buttons
   - `AssetCard`: `⏱` as data label prefix
   - `SettingsPage`: `☀️🌙⚙️` in theme picker
   - Fix: Replace with `van-icon` names or inline SVGs

4. **`inputmode="decimal"` missing on currency fields**
   - All monetary `van-field` use `type="number"` — iOS shows numpad without decimal
   - Fix: Add `inputmode="decimal"` to all currency inputs
   - Affects: Asset form, Liability form

## P2 Issues (Medium Impact)

5. **Safe area insets missing in MainLayout**
   - `padding-bottom: 50px` → needs `calc(50px + env(safe-area-inset-bottom))`
   - Affects: All pages on iPhone with home indicator

6. **Tab bar has 6 items** (max is 5 per Material/HIG)
   - Center "添加资产" button has empty `<span></span>` label
   - Fix: Remove "设置" from tab bar (move to profile icon in header); add `aria-label` to center button

7. **AI features buried in Settings** — no discoverability
   - 7 AI features only accessible via Settings → individual links
   - No AI tab, no contextual entry points from relevant pages
   - Fix: Add AI hub page + contextual entry points

8. **Base font size 14px** — triggers iOS auto-zoom on inputs
   - `body { font-size: 14px }` in style.css
   - Fix: Change to `16px`; use `0.875rem` for secondary text via utility class

9. **No required field indicators on forms**
   - "名称", "购入价格", "当前价值" are required but no `*` or visual indicator
   - Fix: Add asterisk to required labels; add `aria-required="true"`

10. **Family page not in tab bar**
    - Only reachable via Settings or direct URL
    - Active tab shows "总览" when on `/family`

11. **No form navigation-away warning**
    - Partially filled forms lose data on accidental back navigation
    - Fix: Add `beforeRouteLeave` guard with confirmation dialog

12. **`☰▦` view toggles are Unicode glyphs, not SVG icons**
    - DashboardPage.vue:77 — font-dependent rendering
    - Fix: Replace with `van-icon` or inline SVG

13. **Sort popup has no active sort direction indicator**
    - Active state only shows primary color, no arrow/chevron for asc/desc
    - Affects: Asset list sort popup

14. **Filter popup has no "clear all" button**
    - No way to reset selected tags/filters
    - Affects: Asset list filter popup

15. **Dashboard shows truncated list (6 items) with no "show all" CTA**
    - 85 total assets, only 6 shown — no indicator of truncation
    - Affects: Dashboard asset list section

16. **`↑ 186.9% vs 上月` uses color only for positive/negative**
    - No icon or text prefix for colorblind users
    - Fix: Add `↑`/`↓` prefix text + color

17. **No search on Dashboard or Liability list**
    - With 85 assets, no search = poor discoverability

18. **Batch operations icon has no label**
    - Small icon in toolbar, no text label — very low discoverability

19. **AI field suggestion (on asset form) has no user explanation**
    - No indication AI is filling fields; no way to reject suggestions
    - `ai-fill` CSS highlight has no legend

20. **Liability total uses inconsistent number format**
    - Shows raw `¥15,475,000` instead of `¥1547.50万` used elsewhere

21. **No FAB / add button on Asset List or Liability List pages**
    - Users must use center tab bar button — not obvious

22. **Member avatar has no aria-label**
    - Single letter "D" in colored circle — no accessible label on Family page

23. **Invite code has no copy affordance**
    - "CF5B5F" displayed as tappable but no copy icon or "点击复制" hint

24. **`/ai` sub-routes have no parent hub page** (P0 — being fixed separately)

25. **No progress toward wish affordability**
    - Wish cards show expected price but no "you have X% of this" indicator

26. **No `van-floating-bubble` aria-label on Wish List**
    - FAB uses `icon="plus"` with no accessible label
