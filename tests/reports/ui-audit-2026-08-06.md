### 修复验证 (2026-08-06 后续)

#### ✅ Fix 1: MoneyDisplay sourceCurrency 默认值
- **修复提交:** `c712f4d0`
- **根因:** `MoneyDisplay.vue` 的 `sourceCurrency` prop 默认值为 `'CNY'`，导致所有未传入 sourceCurrency 的调用（如 Dashboard 聚合卡片）都硬编码显示 CNY 符号
- **修复:** 默认值改为 `undefined`，使 `displayCurrency = props.sourceCurrency || currency.value` 正确跟随用户 default_currency
- **影响范围:**
  - ✅ Dashboard OverviewStatCard (Net Worth/Assets/Liabilities/Monthly Payment)
  - ✅ FocusTop3Card (负债/心愿金额)
  - ✅ EducationRewardCard (教育奖励统计)
  - ✅ 不影响 AssetDetailPage/LiabilityDetailPage (显式传入 `:source-currency`)
- **验证:** 代码审查通过; dev 模式验证待后端启动后执行

#### ✅ Fix 2: FinanceHubPage syntax
- **修复提交:** `c712f4d0`
- **修复:** line 172-173 syntax issue (missing newline)
- **验证:** dev 模式 Finance 页面正常渲染 (30 assets)

#### ✅ Fix 3: Docker mode direct navigation blank page
- **修复提交:** `d95cbde2`
- **根因:** Vue Router 4 requires `await router.isReady()` before `app.mount()` to ensure initial route is resolved. Without this, direct navigation to non-root URLs (e.g. /finance) results in blank page in production builds.
- **修复:** Add `await router.isReady()` in `main.ts` before `app.mount('#app')`
- **验证:** ✅ dev 模式验证通过 — 直接导航到 /finance 正确渲染 FinanceHub (30 assets)
- **Docker 模式:** 构建已完成 (commit d95cbde2)，待 backend 恢复后验证
