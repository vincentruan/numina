## 修复内容

### 1. Finance Hub 白屏 bug (commit 206bf02a)
**根因**：`MainLayout.vue` 的 `<Transition mode="out-in">` 导致路由切换竞态
- `mode="out-in"` 等待离开动画完成后才进入新组件
- 与 NProgress afterEach timeout (500ms) 产生竞态
- 导航到 `/finance` 时 FinanceHubPage 无法挂载 → 白屏

**修复**：移除 `mode="out-in"`，保留 Transition 用于 CSS 动画

### 2. Finance Hub CSS preload 失败 (commit 3a4f92f7)
**根因**：CSP `style-src` 未包含 Google Fonts
- FinanceHubPage CSS 包含 `@import "https://fonts.googleapis.com/..."`
- CSP 只允许 `'self' 'unsafe-inline'`，阻止了 Google Fonts 加载
- 浏览器触发 `<link>` error 事件 → Vite preload 失败 → Vue Router 拒绝导航

**修复**：CSP 添加 `https://fonts.googleapis.com` (style-src) 和 `https://fonts.gstatic.com` (font-src)
