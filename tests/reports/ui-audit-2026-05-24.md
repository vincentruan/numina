## 已修复 Issues

### P0 — Child SPA 无限重定向崩溃 ✅ Fixed in `2c58b08`
- **Root cause**: vue-router catch-all `redirect: '/child/'` 与 `history.base=/child/` 串联产生无限递归
- **Fix**: `frontend/apps/child/src/router/index.ts:60` → `redirect: '/'`
- **Verified**: 任意 `/child/*` 不存在路径不再崩溃

### P2-1 长目标天数改按年 ✅ Fixed in `f23aa59`
- **Root cause**: `AssetListItem.vue` 对所有 `expected_lifespan_days` 用 `{days}天` 显示，房产 18250天/15915天难以理解
- **Fix**: 阈值 5475 天（15 年）→ 切换到 `progressTargetYears` / `progressRemainingYears`
- **Files**: `AssetListItem.vue`、`zh-CN.ts`、`en-US.ts`
- **Verified**: 房产/家具按年，车辆/数码按天
