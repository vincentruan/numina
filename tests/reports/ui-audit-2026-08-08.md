## AI 功能 Bug 修复

### 问题描述
AI 聊天发送按钮始终处于禁用状态，无法发送消息。

### 根因分析
`useTenantAiResources` composable 的 `onMounted(loadResources)` 在 Pinia family store 填充之前触发。`loadResources()` 在 `!familyId` 检查处 bail out，且之后没有重试机制。

**时序问题**:
1. App.vue `onMounted` → `fetchMe()` → `fetchFamily()` (异步，未 await)
2. AIChatBox/InputBox `onMounted` → `useTenantAiResources()` → `loadResources()`
3. 此时 `familyStore.family?.id` 仍为 null → `loadResources()` 提前返回
4. `models.value` 始终为空 → `context.value.model_name` 未设置 → 发送按钮禁用

### 修复方案
1. 添加 `watch` 导入到 `useTenantAiResources.ts`
2. 添加 `watch(familyId, ...)` 监听器，当 family store 填充后重试 `loadResources()`
3. 仅在 `models.value.length === 0 && !loading.value` 时重试，避免重复调用

### 验证结果
- ✅ `/api/v1/ai/models` 请求成功发出
- ✅ 模型列表正确加载 (3 个模型，默认: qwen3.7-plus)
- ✅ 发送按钮在输入文本后变为可用
- ✅ 点击发送后 API 请求正常 (401 是 bsk 测试 session 的 auth 问题，非功能 bug)
