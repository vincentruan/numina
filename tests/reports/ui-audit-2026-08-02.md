## 已知设计变更 (影响测试路由)

### U6 路由重定向
`/wishes`、`/assets`、`/liabilities` 独立列表路由已重定向到 `/finance?tab=wishes|assets|liabilities`。
FinanceHub 页面整合了三个 tab。测试用例 C2.2/C2.5/C2.8 需改用 FinanceHub tab 验证。

### bsk navigate SPA 路由不同步
**问题**: `bsk navigate http://localhost/wishes` 后浏览器 URL 正确, 但 Vue Router `currentRoute.value.path` 停留在 `/`。
**原因**: Vue Router 初始化时未同步 `window.location.pathname`。
**绕过**: 使用 `bsk evaluate` 调用 `router.replace('/route')` 程序化导航。
**影响**: 仅影响 bsk 自动化测试, 用户正常使用不受影响 (通过底部 Tab 导航正常)。

## 失败详情

### Child App (Area 1) — Docker 模式儿童页面无法加载
- **路由**: http://localhost/child/
- **截图**: 无 (页面未渲染)
- **预期表现**: 儿童选择页 (ChildSelectPage) 显示孩子卡片 (小宝/大宝) 供选择
- **当前错误表现**: `bsk navigate http://localhost/child/` 后页面显示空白或仍为成人 dashboard 内容。Vue Router 停留在成人 SPA 路由, 未切换到儿童 SPA。
- **初步判断**: Docker 模式下 nginx `/child/` → `frontend-child:80` 代理正常 (logs 显示 200), 但 bsk session 的 cookie 是成人 session, 可能干扰儿童 SPA 的路由守卫。儿童 SPA 有自己的路由守卫 (需要 PIN 认证选择孩子), cookie 中的成人 session 可能导致路由冲突。需要单独的 bsk session 或清除 cookie 后重试。
- **建议**: 儿童页面测试需要新 session + cookie 清除, 或使用 dev 模式 (child :5174 独立 origin) 测试。
