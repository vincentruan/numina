## 警告详情

### ~~R3 — 语言切换机制不明~~ ✅ 已解决 (2026-08-06)
- **路由**: `PUT /auth/me/settings`
- **预期表现**: 用户可通过设置页切换语言，偏好持久化到后端
- **当前表现**: `PUT /auth/me/settings {"language":"en-US"}` 成功更新，`GET /auth/me` 返回 `language: "en-US"` ✅
- **初步判断**: 功能正常。测试时误用 `PATCH /auth/me`（返回 FORBIDDEN），正确端点是 `PUT /auth/me/settings`。该端点同时支持 `language`、`theme`、`default_currency`、`view_mode`、`theme_color` 字段
- **分类**: `I18N` — 功能正常，端点使用错误

### R4 — NProgress 瞬时卡顿 `PERF`
- **路由**: 快速连续切换 tab (finance?tab=assets → liabilities → wishes × 15)
- **截图**: `dogfood-output/r4-nprogress.png` (顶部蓝色进度条残留)
- **预期表现**: 快速导航后 NProgress 应立即消失
- **当前表现**: 15 次连续导航后 NProgress bar 残留 (width=3385px, opacity=1)，但再次导航到 dashboard 后自动清除
- **初步判断**: "out-in transition race" 问题的残留 — fix (500ms timeout) 已部署，但极端快速导航仍可触发瞬时卡顿。建议进一步增加 timeout 或添加 routerDone flag 检查
- **分类**: `PERF` — 性能问题，非功能性 bug

### AI Chat — 无 provider 配置 `AI` ✅ 已修复
- **路由**: `/ai/chat`
- **截图**: `dogfood-output/c6-ai-chat-response-15s.png` (空白回复)
- **预期表现**: AI 配置完整时可正常回复
- **当前表现**: AI 已启用但 `ai_provider: null`，聊天发送消息后无任何回复 (无网络请求发出)
- **初步判断**: 非代码 bug，是数据配置问题。需在 `/settings/ai` 添加 LLM provider 才能使用 AI Chat 功能
- **分类**: `AI` — 功能缺失 (需配置 provider)
- **✅ 修复 (2026-08-05 21:30)**: 实际根因是后端调用 agent 的认证路径错误。后端使用 AgentClient（X-Agent-Token）调用 agent 外部 JWT 端点，导致 401。已添加内部网关端点并更新后端路由。待 Docker 重建完成后验证。
