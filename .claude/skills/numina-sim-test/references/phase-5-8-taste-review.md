# Phase 5.8 — Taste Review Details

前端品味审查详细指南。基于 `design-taste-frontend` skill (tasteskill 2.5) 的
核心原则，适配移动 App 截图审查场景。

> **This file is reference material.** The SKILL.md Phase 5.8 section
> describes the workflow. Read this when you need the detailed principles,
> anti-pattern catalog, or review methodology.

## 九条品味原则 (截图审查版)

基于 design-taste-frontend 的 Nine House Rules，适配移动端 App 截图审查：

### P1. 屏幕意图 (Rule 3 — One section per screen)

每个屏幕有一个清晰的焦点/目的。没有信息过载，也没有内容稀疏。

- ✅ Dashboard: 资产总览为主，辅助卡片为辅
- ✅ 单个表单页: 只处理一个实体
- ❌ 一个屏幕塞了三个不相关的功能模块
- ❌ 一个屏幕只有一个标题和一行文字（太空）

### P2. 等宽对齐 (Rule 4 — Equal edges)

内容左右边距一致。所有卡片、列表、标题的左边缘对齐，右边缘对齐。

- ✅ 所有卡片在同一 left padding 起始
- ✅ 列表项左对齐一致
- ❌ 某卡片比上面的缩进多了 4px
- ❌ 右侧有内容溢出或未对齐

### P3. 视觉系统一致 (Rules 1, 7)

- 按钮样式全局不超过 2 种（primary + secondary/ghost）
- 卡片圆角全局一致
- 图标风格一致（Numina 用产品图标，非纯线条风格）
- 配色符合品牌:
  - ✅ 成人版: 冷色调 navy/lavender (`#010120` / `#bdbbff`)
  - ✅ 儿童版: 暖色调 cream/ochre (`#fffaf0` / `#e8b94a`)
  - ❌ 两个 app 用了同一套配色 → 失去个性
  - ❌ 成人版用了暖奶油+赤陶色 (非本 App 调色板)
  - ❌ 儿童版用了暗黑+酸性绿 (非本 App 调色板)

### P4. 动效克制 (Rules 5, 8)

- 按钮有 hover/active 状态（在截图序列中可观察）
- 卡片有微交互迹象（阴影、抬升感）
- 没有过度动效（截图中不应看到动画残影/模糊）
- 动效服务于功能，不只是为了炫技
- 没有滚动驱动的逐屏渐入（fade-in-on-scroll 是反模式）
- 没有视差滚动文字

### P5. 真实感 (Rule 6)

- 产品 UI 展示真实数据，非占位内容（Lorem / "Sample Text"）
- 空状态插图/文案有品牌特色，非通用素材
- 没有 AI 生成的通用插画风格（如果用了插画）
- 数字/金额展示合理，不像随机生成

### P6. 文案品味 (copy.md 原则)

- 没有空洞形容词（"强大的"、"领先的"、"极致"、"赋能"）
- 没有中英文混排滥用（中文 App 不应到处是英文单词）
- 按钮文案是"动词+名词"（"添加资产" ✅ vs "确认" 过于模糊 ⚠️）
- 标题说人话，不用 jargon
- 数字格式正确（金额千分位、小数位一致）

### P7. 首屏定义 (Rule 2 + copy headline)

App 的首屏（Dashboard / ChildHome）是否：
- 一眼看懂这是什么 App
- 有真实数据填充（非空态）
- 主操作按钮突出可见
- 品牌感从首屏就能感知

### P8. 无图片说明 (Rule 1 — No caption)

截图中的装饰性插图/图标：
- 没有多余的文字说明紧跟图片
- 图片/插图自解释
- 如果有 credits，只在一处出现

### P9. 不造轮子 (Rule 8 — 正确场景用正确效果)

- 金融/家庭 App 不需要 shader 背景或 3D 场景
- 儿童 App 可以有游戏化元素（庆祝、金币），但不浮夸
- 暗色主题不应出现酸性绿/霓虹色点缀
- 页面过渡自然，不突兀

## 品味反模式速查 (AI 生成感检测)

以下信号表明页面有"AI 生成感"或"模板感"——在截图中快速扫描：

| 反模式 | 截图中的表现 |
|--------|-------------|
| **SaaS 卡片套件** | 所有内容都在相同圆角卡片里，阴影一致，看起来像一套卡片模板 |
| **排版花哨** | 标题中某个词被斜体/变色/加大；大写字母+宽字间距（中文场景不应出现） |
| **暖奶油+赤陶色** | 成人版用了 `#F4F1EA` + `#D97757` 风格（非本 App 调色板） |
| **暗黑+酸性绿** | 暗色模式配酸性绿点缀（非本 App 暗色方案） |
| **图标风格不一致** | 部分用线条图标、部分用填充图标、部分用彩色图标 |
| **占位内容** | Lorem ipsum、"Sample Text"、空白图表、TODO 注释可见 |
| **过度对称** | 每一行都完全对称、每个卡片大小完全相同（缺乏节奏变化） |
| **无品牌感** | 遮住 logo 后看不出这是 Numina（缺少独有视觉元素） |
| **渐变滥用** | 到处是彩虹渐变、mesh gradient，没有一处纯色留白 |
| **通用素材** | 空状态/引导页用了看起来像 freepik/unDraw 的通用插画 |
| **滚动渐入** | 每个 section 都有 fade-in-on-scroll（在截图序列中可见） |
| **标题格式词** | 用了"赋能"、"生态"、"闭环"等 AI slop 词汇 |

## 审查方法

### 截图采样

从本轮测试截图中选出 **5-10 张关键截图**：

1. **主 Dashboard** (成人版首屏)
2. **核心功能页** (本轮测试的重点 Area 的关键页面)
3. **儿童 App 首页** (ChildHome)
4. **空状态/加载态** (如有)
5. **弹窗/Dialog** (如有)
6. **表单页** (如有)
7. **暗色模式** (如有 — 和本轮 UI quality 截图复用)

### 逐张检查

对每张截图，快速过六条原则（P1-P6 为主，P7-P9 辅助）：
- 符合 → 跳过
- 不确定 → 问自己："如果我 figma.com/x.ai 旁边放这个截图，它看起来像是认真设计的吗？"
- 不符合 → 记录 TASTE-* 代码

### 分级

| 级别 | 含义 | 示例 |
|------|------|------|
| 🔴 阻断 | 布局错乱/文字不可读 | 文字和背景色对比度接近 1:1 |
| 🟡 降级 | 功能可用但体验降级 | 排版不佳、缺少微交互、图标风格不一致 |
| 🟢 轻微 | 不影响使用但降低品牌感 | 品牌感弱、配色不统一、文案 jargon |

### 输出

报告中以 TASTE-* 代码标注：

```markdown
### 品味审查 (Phase 5.8)

**审查截图数:** N (列出截图文件名)

| # | 截图 | 原则 | 问题 | 级别 |
|---|------|------|------|------|
| 1 | c2.1-dashboard.png | P3 视觉系统 | 金额字体与标题字体无区分 | 🟢 轻微 |
| 2 | c1.1-child-home.png | P5 真实感 | 空状态插图像通用素材 | 🟡 降级 |

**品味总结:** {一句话总结整体品味水准，如"品牌感良好，排版细节待提升"}
```

## Numina 特有的品味基准

### 成人版 ("Together AI")

- 深色主题 + 冷色调（navy/lavender）
- 数据可视化为主（ECharts 图表应与主题融合）
- Space Grotesk + Inter 字体组合
- 金融感但不冰冷——家庭场景需要温度

### 儿童版 ("Clay")

- 温暖色调（cream/ochre）+ 圆角
- 游戏化元素（金币、庆祝动画、盲盒）
- 品牌个性鲜明——不同于成人版的严肃感
- Clay 设计语言——有手工/黏土的温暖触感

### 两版一致性

- 交互模式一致（Tab bar 位置、弹窗样式、Toast 位置）
- 但视觉风格有意差异化（见上）
- 空状态/骨架屏风格应属于同一设计系统

## 常见误判

| 误判 | 实际 |
|------|------|
| Vant4 默认样式 = "模板感" | Vant4 是项目选型，其默认样式是有意选择，不标 TASTE |
| 暗色模式截图看起来暗 = "不可读" | 暗色模式本就暗；只有当文字不可读时才标 TASTE/UI-DARK |
| 儿童版风格太"幼稚" | 目标用户是儿童，"幼稚"是设计意图，不标 TASTE |
| 截图分辨率低导致模糊 | 这是截图质量问题，不是产品品味问题 |
| ECharts 图表默认配色 | 图表配色应检查是否适配主题，但不标 TASTE（标 UI-DARK 或 DATA） |
