思维流：
  1. 图片 → 拍照建立视觉锚点
  2. 名称 → 这是什么
  3. 分类 → 属于哪类
  4. 购入价 → 当前价值 → 值多少钱
  5. 购入日期 → 什么时候买的
  6. 使用频率 → 预期寿命 → 怎么用、用多久（日均成本核心输入）
  7. 存放位置 → 年维护费 → 在哪、花多少维护
  8. 标签 → 备注 → 补充信息
✦ 使用频率提前到预期寿命之前：两者都是"日均成本"的核心输入，放在一起语义更连贯
