功能特性

资产管理

  • 实物资产追踪（房产、车辆、数码、家电等 13 个分类）
  • 金融资产追踪（存款、基金、股票、债券等 8 个分类）
  • 自定义分类与标签
  • 资产价值更新与历史记录
  • 日常使用成本计算（日均成本）

负债管理

  • 房贷、车贷、信用卡、个人贷款全覆盖
  • 还款进度追踪
  • 关联资产（如房贷关联房产）

数据可视化

  • 净资产趋势折线图（ECharts）
  • 资产分配饼图
  • 家庭财务健康仪表盘
  • 每日净资产快照

家庭协作

  • 多用户角色：管理员（owner）/ 成员（member）/ 孩子（child）
  • 6 位邀请码加入家庭
  • 家庭级数据隔离

孩子系统

  • PIN 码认证，专属儿童界面
  • 星星硬币激励系统
  • 家务模板与审批队列
  • 心愿兑换（积分换资产）
  • 连续打卡与里程碑庆典

技术架构

后端

  • FastAPI (Python)
  • SQLAlchemy ORM
  • SQLite / MySQL / PostgreSQL
  • JWT 认证（bcrypt + access/refresh tokens）
  • Alembic 数据库迁移

前端

  • Vue 3 + TypeScript
  • Vite 构建工具
  • Vant 4（移动端 UI）
  • ECharts（图表）
  • Pinia 状态管理

基础设施

  • Docker Compose
  • Nginx 反向代理
  • GitHub Actions CI/CD
  • Playwright E2E 测试

一键启动

查看完整部署指南 →
  1. 克隆仓库
    git clone https://github.com/vincentruan/numina.git && cd numina
  2. 配置环境变量
    复制 .env.example 为 .env，设置 SECRET_KEY
  3. 启动服务
    docker-compose up -d
  4. 访问应用
    打开浏览器访问 http://localhost:8080

配置参考

变量名 默认值 说明
SECRET_KEY ⚠️ 必填 JWT 签名密钥，生产环境必须设置
DATABASE_URL sqlite:///./data/numina.db 数据库连接字符串
CORS_ORIGINS ["*"] 允许的 CORS 来源
PORT 8080 Nginx 监听端口

⚠️ 生产环境必须设置 SECRET_KEY，否则重启后所有用户会话失效。

数据库选项

SQLite（默认，零配置）

sqlite:///./data/numina.db

MySQL

mysql+pymysql://user:password@host:3306/database

启动：docker-compose --profile mysql up -d

PostgreSQL

postgresql+psycopg2://user:password@host:5432/database

启动：docker-compose --profile postgres up -d
